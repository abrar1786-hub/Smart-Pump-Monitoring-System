# Smart Pump Monitoring System 🚰⚡

## 📌 Project Overview
This project is an IoT-based smart pump monitoring and protection system using ESP32.  
It detects faults in real time and prevents pump damage through automatic shutdown.

---

## 🎯 Objectives
- Monitor pump health using sensors  
- Detect faults like dry run, overheating, and vibration issues  
- Send real-time alerts to users  
- Automatically turn OFF the pump during risk  

---

## ⚙️ Components Used
- ESP32  
- Temperature Sensor (DS18B20)  
- Vibration Sensor (MPU6050)  
- Current Sensor (ACS712)  
- Flow Sensor (YF-S201)  
- Relay Module  

---

## 🔄 Working Principle
Sensors collect real-time data → ESP32 processes data →  
Fault detected → Alert generated → Pump automatically turned OFF  

---

## 🚨 Faults Detected
- Dry Run (No water flow)  
- Overheating  
- Overcurrent  
- Abnormal Vibration
